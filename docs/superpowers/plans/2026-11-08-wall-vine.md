# Wall Pits and Vines Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Pits on vertical walls; Bloom long-presses to take a seed in hand and throws it into a pit, where a standable vine grows horizontally out of the wall.

**Architecture:** A vine is a `plant` whose pit carries `wall: 1 | -1`; it reuses the mushroom's age / speed / freeze / wither code in `src/logic.js` and differs only in its length function, standable surface, side collision and drawing. A new `takeSeed` action turns one counted seed into a held seed object that the existing `grab` throw path launches; a seed in flight (`thrown: true`) that reaches an empty pit plants it.

**Tech Stack:** Plain ES modules, Bun (`bun test`), Canvas 2D renderer, WebSocket rooms (`src/rooms.js`).

Spec: `docs/superpowers/specs/2026-11-08-wall-vine-design.md`.

**Refinement over the spec:** only seeds *in flight* plant (`thrown` flag set on throw, cleared when the seed lands or is caught). Otherwise a level seed lying near a pit, or a seed dropped on a hit, would plant itself.

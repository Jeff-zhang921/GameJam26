# 第二关重做：踩着守卫上高台

日期：2026-11-08

## 目标

替换现有的第二关 rootrise，仿照第一关的结构，做得稍长、稍难，并加入一个在地上走的怪物（现成的守卫 `guard`）。守卫必须被冻慢后当垫脚使用。

## 布局（宽 2560）

| 平台 | x | y | 说明 |
|---|---|---|---|
| P0 起点台 | 0–700 | 500 | 出生点、Bloom 充能、沙漏 |
| P1 月门台 | 1980–2560 | 180 | 月门。沿用"platform-1 是月门所在平台"的约定 |
| P2 中台 | 1500–1940 | 390 | 检查点、沙漏，右端有坑 |
| 低沟 | 700–1500 | 580 | 守卫在这里巡逻，唯一的种子掉在沟底 |

- 低沟比 P0 低 80，可以跳回去。
- P2 比沟底高 190，普通跳（约 160）够不着，站在守卫头上（+50）可以够到。
- P1 比 P2 高 210，只能靠 P2 右端坑里长出的蘑菇上去。

## 规则

- 全关一颗种子，没有箱子。
- 冻结次数：开局 1 次，两个沙漏各加 1 次。
- 低沟里没有坑；守卫的巡逻范围限定在低沟内。
- `exitNeedsPlant: true`。
- 建议目标：`guardRide`（站在被冻慢的守卫上，新增 flag）、`treeLifted`。

## 测试

- 新增 `tests/level-two.test.js`：

  - 沟底普通跳上不了 P2；
  - P2 不靠蘑菇上不了 P1；
  - 守卫出不了沟；
  - 按设计路线可以通关（冻住守卫、踩它上 P2、种蘑菇上 P1）。

# Moonclock 时间流速机制重设计

日期：2026-11-07

## 目标

把现有的"冻箱子 / 树长高 / 回声压机关"玩法，替换为统一的"每个物体有自己的时间流速"模型。删除回声和压力板，重做 4 个关卡。

## 核心规则

### 世界默认静止

- 每个**时间物体**（植物、移动平台）有自己的时间流速。没被 Bloom 碰过的物体永远不会变化。
- "时间"只管生命阶段和平台运动，**不管重力**：箱子和种子始终受重力影响，抛出的箱子照常飞行。

### 时间物体的状态

| 字段 | 含义 |
|---|---|
| `kind` | `plant` / `mover` / `crate` / `seed` |
| `age` | 植物已经历的时间（tick × 流速，仅 `plant`） |
| `withered` | 是否已枯萎（仅 `plant`） |
| `speed` | 时间流速：0 = 静止，1 = 正常，>1 = 加速（`plant`、`mover`） |
| `frozen` | 是否被 Still 冻住（`plant`、`mover`、`crate`） |

### 植物生长（线性，单向）

植物没有离散阶段，只有一个不断增加的 `age`（单位 tick，乘以流速累加）：

- **生长期**：高度从 0 线性长到 235。正常速度下用时 16 秒（`growTicks` = 960）。
- **成熟期**：长满后保持满冠繁茂 8 秒（`matureTicks` = 480）。
- **枯萎期**：之后枯萎（`withered = true`）。树干可以穿过，顶端仍可站立，持续 8 秒（`witherTicks` = 480）。预设的古树开局处在成熟期末尾，唤醒后立即枯萎。
- **消失**：之后植物被移除，土坑空出，可以再种。
- **弹跳点**：高度 ≤ 45 且未枯萎的植物（年幼的芽）。从上面起跳，高度约为平地的 1.5 倍。
- **托人**：树冠宽度随高度连续变宽（40 → 138）。植物从坑里长出时，站在坑上的角色会被接住，并随植物一起升高。高度超过 45 后，被托起才算 `treeLifted`。
- 种下时高度为 0，静止，等待 Bloom 唤醒。

### Bloom（催生者，F）

- 目标：范围内最近的**已种下的植物**或**移动平台**。
- 目标静止（`speed = 0`）时：激活，`speed = 1`。
- 目标已激活时：流速提高一档，植物和移动平台都适用，最高 3 档（`maxSpeed`），满档时提示 `maxSpeed`。
- Bloom 无法停止时间，只有 Still 能停。
- **目标被冻住时按 F：解冻**。物体按冻结前的流速继续，冻结前是静止的植物会同时被唤醒到 ×1。冻住的箱子也能用 Bloom 解冻，会带着原速度继续飞；没冻住的箱子 Bloom 不能碰。标签显示金色的 "Release · F"。
- 目标已经满档时，标签变成灰色的 "Full speed"，提示再按 F 没有用。
- 对没冻住的箱子、未种下的种子按 F 无效：它们不在候选目标里。

### Still（凝时者，F）

- 目标：范围内最近的植物、移动平台或**没被人拿着的**箱子。
- 切换 `frozen`。冻住时阶段进度、位置、速度（包括箱子抛出的速度）全部保持不变，在空中也会悬停。
- 释放后恢复冻结前的流速和运动。
- 冻结状态会一直保持，直到被释放。

### 箱子

- 每关预放，没有生命链，不会消失。
- E 键拿起或抛出，规则和现在一样。拿起不会激活任何时间。
- Still 可以冻住箱子，包括抛出后在空中的箱子；冻住的箱子可以站。

### 种子

- 种子是关卡里预放的**实体物品**，每关的种子数量就是这关的上限。HUD 显示"还没种下的种子数"。
- 任一角色按 **E** 拿起种子，一次只能拿一样东西（种子或箱子）。
- 拿着种子按 **E**：
  - 靠近一个**空土坑**（水平距离 ≤ 50）时：种下。种子固定在坑里，成为 `plant`，处于静止状态。
  - 其他地方：**放在脚下**（不抛出），受重力落地，可以再捡起。
- 只有种在坑里的种子能被 Bloom 激活。
- 一个坑同时只能种一颗。

### 移动平台（mover）

- 沿固定线段来回移动，没有生命链，不会消失。
- 默认静止。Bloom 激活后以基础速度移动，再按 F 提速，最高 3 档。
- Still 冻住后停在当前位置。站在上面的角色会跟着平台一起移动。

## 删除的内容

- 回声（`echo` 动作、`echoes` 状态、Q / K 键、相关文案和绘制）
- 压力板（`plates`）
- Bloom 的逆转能力（Shift + F、`reverse` 参数）

## 辅助机制

### 回溯（R）

- 每 10 tick 记录一次快照，最多保留 19 帧，约 3 秒。
- 只恢复**世界物体**：植物、移动平台、箱子、种子、土坑占用。**角色位置不动**。
- 回溯时，所有角色手上清空。快照里被拿着的物品，放回该角色当前的脚下。
- 已收集的时间碎片不会被回溯撤销。
- 每关限 **3 次**，HUD 显示剩余次数。重置庭院时恢复为 3。

### 重置庭院

一键重新开始本关，保持现有实现。

### 卡住提示

- 每关两级提示文字。
- 进关时"庭院低语"显示第一级提示。
- 状态里记录 `lastProgressTick`：进关时，以及每完成一个关卡目标（`needs` 中的 flag 第一次变为 true）时更新。
- 如果 `elapsed - lastProgressTick ≥ 90 秒`，UI 切换为第二级提示，并让提示卡闪一下。完成新目标后切回第一级，重新计时。

### 计时

- 状态里记录 `elapsed`（tick），只在 `status === 'playing'` 且角色第一次移动之后才累计。
- 关卡内显示通关用时（mm:ss）。
- 通关弹窗显示本关用时和最佳用时。最佳用时存 localStorage（`moonclock-v1` 里新增 `best: [ticks|null × 4]`）。
- 没有倒计时、失败条件、体力条。

### 时间碎片

保留，每关一个，可选收集，规则和现在一样。

### 单人 / 双人

- 单人：Tab 切换角色，规则和双人相同。
- 双人：Still 使用 A/D、W、E、F；Bloom 使用 ←/→、↑、Enter、L。
- 技能目标只按"离当前角色最近、能用的那个"自动选择，不支持鼠标点选。
- 界面按钮只响应鼠标点击。点击后焦点不会停在按钮上，空格和回车始终交给游戏，不会触发任何按钮。

## 关卡（待定）

关卡地图后续单独设计，本轮只确定机制。在那之前，4 个关卡使用临时布局：每关都能加载，并分别展示一种机制（冻箱子、种树托人、催枯古树加幼苗弹跳、移动平台），但不保证可解性和难度。临时布局用到的目标 flag 有：`frozenTouched`、`treeLifted`、`withered`、`sproutJump`、`moverRide`。

所有关卡的通关条件不变：所有目标完成后月门亮起，任一角色走进月门即通关。

## 代码改动

- **`src/logic.js`**
  - 用统一的 `objects` 列表（`plant` / `mover` / `crate` / `seed`）和 `pits` 列表，替换 `crates` / `trees` / `echoes` / `plates`。
  - `ageObjects()`：每 tick 推进植物阶段和平台运动。
  - `surfaces()`：按阶段生成碰撞面，幼苗面带 `spring: true`。
  - `grab` 动作：处理拿起箱子或种子、抛出箱子、种下或放下种子。
  - `ability` 动作：按角色区分 Bloom 和 Still 的逻辑。
  - 删除 `echo` 动作。回溯只恢复世界物体。
  - 新增 `rewindsLeft`、`elapsed`、`lastProgressTick`、`started`。
- **`public/render.js`**：植物按 5 个可见阶段绘制；新增土坑、种子、移动平台的绘制；激活中的物体加一圈缓慢转动的光环；删除回声和压力板。
- **`public/client.js`**：删除 Q / K 回声键；HUD 显示种子数、回溯次数、用时；实现两级提示切换；通关弹窗显示用时和最佳用时。
- **`public/strings.js`**：英文文案按新规则和两级提示重写，关卡文案对应临时布局。

## 测试（`tests/logic.test.js`）

- 静止的植物不会老化；被 Bloom 激活后线性长高；Bloom 能解冻被 Still 冻住的物体（包括空中的箱子）。
- 对已激活的植物再按 F，立即进入下一阶段。
- 冻住后阶段、位置、速度不变；释放后恢复原流速。
- 枯枝走完后植物消失，站在上面的角色掉落，坑空出。
- 从幼苗起跳比平地跳得高。
- 拿着种子在空坑旁按 E 会种下，在别处按 E 会放在脚下；地上的种子不响应 Bloom。
- 一个坑不能种两颗。
- 冻住的箱子悬在空中；Bloom 对箱子无效。
- 回溯恢复世界物体，角色位置不变，手上清空；每关最多 3 次。
- 移动平台：静止时不动，激活后会动，冻住后停下，站在上面的角色跟着平台走。
- 卡住提示：计时从第一次输入开始；空闲 90 秒后提示升级；完成目标后恢复。
- 保留：房间权限 / 非法动作校验、碎片不重复计数。

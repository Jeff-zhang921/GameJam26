三张精灵图均为1254×1254 PNG，4列×4行，从左至右、从上至下读取。带透明通道。

实际输出尺寸不是2048像素。按整数坐标切图时，横纵边界均可使用0、313、627、940、1254；相邻格子宽高交替为313或314像素。

常驻动画以中央站立面稳定为设计目标；游戏中的碰撞平台应单独固定，不随外围细绒移动。严格凝时可直接暂停一帧。
